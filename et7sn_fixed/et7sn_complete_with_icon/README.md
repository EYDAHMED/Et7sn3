# Olive Fit

Flutter app (Arabic + English, Olive Green / White theme): Firebase Email/Password auth, onboarding,
daily Egyptian diet plan (BMR/TDEE + Skip/Replace), GPS prayer times with live countdown,
weekly weight-loss leaderboard, and a super-admin dashboard.

> This zip contains the Dart source, Firestore rules and admin script. The `android/` and `ios/`
> platform folders are generated by Flutter in step 1 (they weren't created here because no Flutter SDK was available).

## 1. Generate the platform folders (once)

```bash
cd et7sn
flutter create --org com.yourname --project-name et7sn .
flutter pub get
```

`flutter create .` keeps the existing `lib/` and `pubspec.yaml`. Use your own `--org` (it becomes the Android package id).

## 2. Connect Firebase

```bash
dart pub global activate flutterfire_cli
firebase login
flutterfire configure          # creates lib/firebase_options.dart + android/app/google-services.json
```

In the Firebase Console enable **Authentication → Email/Password** and create a **Firestore** database,
then deploy the rules:

```bash
firebase deploy --only firestore:rules
```

If the Android build complains about the minimum SDK, set `minSdk = 23` in `android/app/build.gradle(.kts)`.

## 3. Permissions

**Android** — `android/app/src/main/AndroidManifest.xml` (inside `<manifest>`, above `<application>`):

```xml
<uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION"/>
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION"/>
```

**iOS** — `ios/Runner/Info.plist`:

```xml
<key>NSLocationWhenInUseUsageDescription</key>
<string>Used to calculate accurate prayer times for your location.</string>
```

## 4. Make yourself admin (optional)

```bash
npm install firebase-admin
export GOOGLE_APPLICATION_CREDENTIALS=/path/to/serviceAccountKey.json
node scripts/set_admin.js you@example.com
```

Sign in with that account and an **Admin** tab appears. Never commit the service-account key.

## 5. Run and build

```bash
flutter run
flutter build apk --release                    # build/app/outputs/flutter-apk/app-release.apk
flutter build apk --release --split-per-abi    # smaller per-CPU APKs
flutter build appbundle --release              # for Google Play
```

For a Play-Store-ready release, create a signing key and add a `key.properties` + `signingConfigs`
block to `android/app/build.gradle.kts` (see the Flutter docs: "Build and release an Android app").
Without that, the release APK is signed with the debug key — fine for sideloading and testing.

## Notes

- Calories and macros in `lib/data/egyptian_meals.dart` are approximations — review them (ideally with a dietitian).
- Prayer times use the Egyptian General Authority of Survey method and are computed on-device.
- Leaderboard weights are self-reported.
